## Шаг 5: Разметка запрещённой зоны

### 5.1 Запуск утилиты разметки

```powershell
python -m src.tools.mark_restricted_zone
```

**Что произойдёт:**
- Откроется окно OpenCV с первым кадром видео
- В консоли появятся инструкции

### 5.2 Инструкции по разметке

**В окне OpenCV:**

1. **Добавление точек полигона:**
   - Кликните левой кнопкой мыши по углам зоны, которую хотите отметить
   - Каждый клик добавляет точку (зелёный кружок)
   - Точки соединяются жёлтой линией

2. **Сохранение зоны:**
   - Нажмите клавишу `s` (save)
   - Зона сохранится в `restricted_zones.json`
   - Окно закроется

3. **Сброс текущей разметки:**
   - Нажмите клавишу `r` (reset)
   - Все точки удалятся, можно начать заново

4. **Выход без сохранения:**
   - Нажмите `q` или `ESC`
   - Окно закроется, изменения не сохранятся

### 5.3 Проверка сохранённой зоны

```powershell
Get-Content restricted_zones.json
```

**Ожидаемый результат**: JSON с массивом зон, например:
```json
[
  {
    "id": "zone_1",
    "name": "Restricted area 1",
    "points": [[100, 100], [200, 100], [200, 200], [100, 200]]
  }
]
```

**Если файл пустой или зона не сохранилась:**
- Запустите утилиту разметки снова
- Убедитесь, что добавили минимум 3 точки
- Нажмите `s` для сохранения

## Шаг 6: Запуск системы детекции

### 6.1 Запуск основного приложения

```powershell
python -m src.main
```

**Что произойдёт:**
- Загрузятся зоны из `restricted_zones.json`
- Загрузится YOLO-модель (при первом запуске может занять время)
- Откроется окно с видео
- Начнётся обработка кадров в реальном времени

### 6.2 Что вы увидите в окне

**Визуальные элементы:**
- **Жёлтые линии** - границы запрещённых зон
- **Зелёные прямоугольники** - детектированные люди (bounding boxes)
- **Синие точки** - центры детекций (для проверки попадания в зону)
- **Красная надпись "ALARM!"** - активная тревога

### 6.3 Поведение системы

**Активация тревоги:**
- Когда центр детекции человека попадает внутрь полигона зоны
- Надпись "ALARM!" появляется мгновенно

**Деактивация тревоги:**
- Когда все люди выходят из всех зон
- Тревога гаснет через 3 секунды (cooldown)

### 6.4 Управление

- **Выход**: Нажмите `q` или `ESC`
- Окно закроется, видео остановится

## Шаг 7: Проверка работы системы

### 7.1 Тест 1: Детекция людей

**Проверьте:**
- ✅ Появляются ли зелёные прямоугольники вокруг людей
- ✅ Видны ли синие точки в центрах детекций

**Если люди не детектируются:**
- Убедитесь, что видео содержит людей
- Попробуйте уменьшить `CONFIDENCE_THRESHOLD` в `src/config.py` (например, до 0.3)

### 7.2 Тест 2: Активация тревоги

**Проверьте:**
- ✅ Когда человек входит в зону, появляется ли "ALARM!"
- ✅ Когда человек выходит, тревога гаснет через 3 секунды

**Если тревога не активируется:**
- Проверьте, что зона правильно размечена
- Убедитесь, что центр детекции (синяя точка) попадает внутрь полигона

### 7.3 Тест 3: Cooldown механизм

**Проверьте:**
- ✅ Когда человек выходит из зоны, тревога не гаснет мгновенно
- ✅ Тревога гаснет ровно через 3 секунды после последнего выхода

## Шаг 8: Настройка параметров (опционально)

### 8.1 Редактирование конфигурации

Откройте файл `src/config.py` в текстовом редакторе:

```python
# Можно изменить:
CONFIDENCE_THRESHOLD = 0.5  # Порог уверенности детекции (0.0-1.0)
IOU_THRESHOLD = 0.45         # Порог для NMS
ALARM_COOLDOWN_SECONDS = 3.0 # Время задержки перед выключением тревоги
DEVICE = "cpu"               # "cpu" или "cuda" (если есть GPU)
```

### 8.2 Применение изменений

После изменения `src/config.py` просто перезапустите:
```powershell
python -m src.main
```

## Возможные проблемы и решения

### Проблема 1: "Cannot open video"

**Причина**: Файл `data/test.mp4` не найден или повреждён

**Решение**:
```powershell
Test-Path data\test.mp4
# Если False - проверьте путь и имя файла
```

### Проблема 2: "No restricted zones defined"

**Причина**: Файл `restricted_zones.json` пустой или не содержит зон

**Решение**:
```powershell
python -m src.tools.mark_restricted_zone
# Разметьте зону и сохраните (клавиша 's')
```

### Проблема 3: Медленная работа

**Причина**: Используется CPU вместо GPU

**Решение**:
1. Установите CUDA и cuDNN (для NVIDIA GPU)
2. Установите PyTorch с CUDA: `pip install torch torchvision --index-url https://download.pytorch.org/whl/cu118`
3. Измените в `src/config.py`: `DEVICE = "cuda"`

### Проблема 4: Ошибка импорта модулей

**Причина**: Виртуальное окружение не активировано

**Решение**:
```powershell
.venv\Scripts\Activate.ps1
python -m src.main
```

### Проблема 5: YOLO модель не загружается

**Причина**: Проблемы с интернетом или правами доступа

**Решение**:
1. Проверьте интернет-соединение
2. Модель скачается автоматически при первом запуске
3. Проверьте папку `~/.ultralytics/` на наличие модели
